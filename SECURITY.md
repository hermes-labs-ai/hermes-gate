# Security Policy

## Supported versions

HermesGate is pre-1.0 software. Security fixes are prepared for the latest released
minor version.

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Earlier | No |

## Reporting a vulnerability

Use the repository's private report form at
`https://github.com/hermes-labs-ai/hermes-gate/security/advisories/new`. If that
form is unavailable, email `rbosch@lpci.ai`. Keep exploit details out of public
issues and discussions.

Include the affected version, a minimal reproduction, impact, and any suggested
mitigation. Do not include credentials, private source, or client data. Maintainers
will acknowledge a complete report, investigate it, and coordinate disclosure.
